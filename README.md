# SlimKit 🏃

Application de perte de poids par la marche avec analyse IA des repas.

## Stack
- **Frontend** : React + Vite + Nginx
- **Backend** : Node.js + Express
- **Infra** : AWS EC2 + ECR + Terraform
- **CI/CD** : GitHub Actions

## Déploiement
```bash
git push origin main  # déclenche le pipeline automatiquement
```
